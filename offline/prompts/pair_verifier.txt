A reusable ambiguity edge means that, in realistic text-to-SQL use, the same underspecified user wording could reasonably schema-link to either column, and choosing one column instead of the other can change the SQL or the intended semantic interpretation.

Use the provided column context, value-overlap statistics, declared schema constraints, and table context to determine whether the pair is likely ambiguous.

1. At least one realistic, non-corner-case underspecified user request makes both columns plausible schema-linking targets. In other words, a concrete ambiguity trigger context exists.
2. Selecting one column rather than the other can change projection, filtering, grouping, aggregation, join path, entity scope, row grain, representation, or semantic interpretation.
